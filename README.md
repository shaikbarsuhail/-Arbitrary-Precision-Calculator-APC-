# Arbitrary Precision Calculator (APC)
## Description
This project implements an Arbitrary Precision Calculator (APC) in C using doubly linked lists to perform arithmetic operations on large integers beyond the limits of standard data types.


## Features
- Addition
- Subtraction
- Multiplication
- Division
- Command-line argument validation
- Dynamic memory allocation

## Technologies Used
- C Programming
- Doubly Linked Lists
- Pointers
- Dynamic Memory Allocation


## Compilation
```bash
gcc *.c 
```

## Execution
```bash
./a.out 123456789 + 987654321
```
